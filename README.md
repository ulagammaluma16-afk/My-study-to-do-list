# 🎓 Semester & Skills Dashboard

A modern **one-page personal academic dashboard** created to showcase my **3rd semester papers, 6  papers, and technical skills** in one place.

## 📌 About the Project

This project is a simple personal dashboard that brings my academic subjects and technical skills together in a clean, organized, and attractive interface.

The dashboard contains:

* 📚 3rd Semester Papers
* 📖 6th Semester Papers
* 💻 Technical Skills
* 📊 Skill Levels
* 🎯 Learning Progress

## ✨ Features

* 🎓 3rd Semester subject section
* 🎓 6th Semester subject section
* 💻 Technical skills section
* 📊 Skill progress indicators
* 📱 Responsive one-page design
* 🎨 Modern and clean UI
* ⚡ Easy navigation
* 🖥️ Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
